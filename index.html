金融機関の自衛設定

金融機関・証券会社で「自分で」入れられる防御設定まとめ

調査日: 2026-10-08(各社公式ページ・FAQ・お知らせを中心に確認)

仕様とメニュー名は頻繁に変わります。設定するときは、メールやSMSのリンクではなく、ブックマークか公式アプリから入ってください。

凡例: ◎ = 効果が大きく最優先 / ○ = 入れておきたい / 自動 = 設定不要で適用済み

0. 全社共通の考え方

攻撃の流れは「ID・パスワードを盗む → ログイン → 売却・買付・出金」なので、守りは3層に分けて考えると整理しやすいです。

層 狙い 代表的な設定
1. 入らせない フィッシングで盗まれても入れない状態にする パスキー登録 + パスワードログインの無効化
2. 入られても動かせない 売却・出金・送金を止めておく 取引制限、出金先変更ロック、振込限度額0円、利用停止
3. すぐ気付く 被害を小さくする ログイン通知、注文・出金通知、ログイン履歴の確認

「取引や出金を止めておく」機能がある証券会社:

会社 自分で即時に設定 電話・フォームで依頼
楽天証券 取引やサービスの一時的な利用停止(5種類から選択) 出金先変更のロック
マネックス証券 取引・サービスの一時的な利用停止 売買・入金・出金の個別制限
SBI証券 ログインの一時停止、アプリ・ツールのログイン制限 取引制限
松井証券 全停止・取引停止・出金制限・商品指定、出金先変更のロック

押さえておきたい点:

  • パスキーを登録しただけでは不十分です。パスワードでのログインが残っていれば、攻撃者はそちらを使います。「パスワード無効化」「パスキーのみ」の設定がある会社では、そこまで行ってください。
  • パスキーのみにすると、端末の故障・紛失時に入れなくなります。複数端末に登録し、復旧手段(電話窓口、本人確認書類)を先に確認しておいてください。
  • パスキーの保管先(Appleアカウント、Googleアカウント、パスワードマネージャー)が次の弱点になります。そちらのパスワードを長くし、二段階認証を有効にしてください。
  • 出金や出金先変更の認証コードがメールに届く会社では、メールアカウントの防御が口座の防御と同じ重みを持ちます。
  • 登録の電話番号とメールアドレスが古いと、通知も復旧も機能しません。最初に確認してください。
  • 銀行は証券ほどパスキー化が進んでいないため、現状の主な自衛手段は「振込限度額を下げる」「使わない機能を止める」「認証をアプリ方式にする」の3つです。限度額の引き下げは多くの銀行で即時、引き上げは時間がかかるため、普段は低くしておくのが有効です。

1. 証券会社

SBI証券

優先 設定 内容 場所・注意
◎ パスキー認証 2026/6/30から原則必須化。最大10個まで登録可 ログイン後「セキュリティ設定」。取引パスワードとメールの認証コードが必要
◎ ログインパスワード無効設定 ユーザーネーム・パスワードでのログインを止め、パスキーのみにする。対象はメインサイト(PC・スマホ)、スマホ専用サイト、SBI証券Plus パスキー登録が前提。「My設定 → 各種サービス」で、設定を「設定しない(ログインパスワード利用可)」から「設定する(ログインパスワード利用不可)」に変更する。2026/7/10夜以降は、有効にするとアプリ・ツールのログイン制限も自動で適用される
○ アプリ・ツールのログイン制限設定 使わないアプリ・ツールからのログインをツール単位で止める WEBサイトから設定。使っているアプリがあると、パスワード無効化がエラーになる場合がある模様
○ ログイン一時利用停止/解除 全チャネルのログインを一時的に止める。取引しない夜間などに使う 次回ログイン時に解除。法人口座は不可
○ 取引制限(依頼制) 外国株の買付停止や出金停止などを、カスタマーサービスに依頼してかけてもらう 問い合わせフォーム・電話・チャットで依頼し、解除は電話。希望内容(例: 中国株を含む外国株式の新規買付停止)を具体的に伝える
○ 電話番号認証 パスワードログインを残す場合の追加認証。登録電話番号から発信して認証する パスキーのみにできない人向けの次善策
○ ログイン通知メール / ログイン履歴 不審なログインに気付く 履歴は日時とチャネルを確認できる
自動 出金時の二要素認証 出金指示のときにメールで認証コードが届く
自動 出金先口座の変更 取引パスワードとメールの認証コードが必要。出金先は1口座のみ登録可

楽天証券

優先 設定 内容 場所・注意
◎ パスキー認証(FIDO2) 2025/10/26導入。2026年6月以降、順次必須化(時期は個別に案内) 2026/5/31からスマホなしでも作成可。使えない場合はメールの絵文字認証が必須
◎ 取引やサービスの一時的な利用停止 下の5種類から選んで止める PC:「セキュリティ設定 → 取引やサービスの一時的な利用停止」。スマホ:「マイメニュー → セキュリティ設定 → 取引の一時的な利用停止」タブ。種類を選んで「認証へ進む」。設定・解除とも登録電話番号への音声ワンタイムキーで本人確認
○ 出金先指定口座の変更停止 出金先の変更機能をロックする カスタマーサービスセンターに電話して依頼
○ 注文通知 注文の受付・訂正・取消でメールが届く 商品ごとに設定(2025/10/26開始)
自動 ログイン通知メール / ログイン履歴 履歴は過去3か月分
自動 出金時の追加認証 SMSまたは音声のワンタイムキー(2025/10/26から必須) 出金先は本人名義の登録口座のみ

利用停止の5種類(設定できるのは同時に1種類だけ):

種類 使える操作 止まる操作 向いている人
投資信託の買付以外を停止 ログイン、入金、投信の買付・積立、配当金・分配金・利金の受取と再投資 出金、投信の売却、外国株式などその他商品の取引 投信積立だけの人
投資信託と出金以外を停止 ログイン、入金、出金、投信の買付・売付・積立、配当金等の受取と再投資 その他商品の取引 投信の売買と出金は使う人
外国株式のみ停止 外国株式以外 米国・中国・アセアン株式の取引 外国株を使わない人(不正取引で悪用されやすい中国株などを止める)
すべての取引を停止 ログイン 取引全般 残高確認だけしたい人
ログイン・すべての取引を停止 なし ログインを含むすべて 長期間触らない人

設定すると、同じ画面の「適用中の利用停止設定」に種類が表示され、「変更」「解除」のボタンが出ます。

注意点:

  • 個別株の売買やデイトレードをする人は、上2つを選ぶと取引できなくなります。
  • 逆指値注文は停止中は執行されず、解除時に想定外の価格で約定することがあります。設定前に取り消してください。
  • 投信の買付まで止まる種類(すべての取引を停止など)では積立注文がエラーになります。iDeCoの拠出と配当金の受取は続きます。
  • ログインを含む停止の解除は、自動音声ダイヤル(0120-852-638)に登録電話番号からかけて行います。

マネックス証券

優先 設定 内容 場所・注意
◎ パスキー認証 2026/6/30にログイン時のパスキー認証を必須化。公式FAQでは、登録後は従来のID・パスワードでログインできなくなる ログイン後「パスキー登録状況」。複数登録可。2個目以降の追加は既存パスキーでのログインが必要
○ ワンタイムパスワード 登録情報の照会・変更と出金指示で使う。認証アプリとSMSがあり、認証アプリが推奨 ログイン時のワンタイムパスワードは廃止予定
◎ 取引・サービスの一時的な利用停止 自分で即時に止められる。出金と株・投信・債券などの取引が止まり、ログイン、残高確認、入金、設定済みの投信積立は続く 「MY PAGE → 登録情報 → 取引・サービスの一時的な利用停止」で「登録」し、取引パスワードを入力。メールアドレス1の登録が必要
○ 取引制限(依頼制) 売買、即時入金、出金・即時出金を個別に制限してもらう 問い合わせフォームまたはコールセンターに依頼。設定完了まで2営業日程度かかる場合あり。解除は書類郵送か電話(書類は1〜2週間程度)

一時的な利用停止の注意点:

  • 解除には取引パスワードの再設定が必要で、すぐには戻せません。方法は、オンライン(パスキー登録とマイナンバーカードでの本人確認)、郵送、電話の3つです。
  • スマホアプリと登録情報の照会も使えなくなります。家計簿アプリとの連携は切れ、解除後に再連携が必要です。
  • 米国株のスマホアプリは、ログアウトしないとセッションが残ります。

松井証券

優先 設定 内容 場所・注意
◎ パスキー登録 2026年6月から登録必須 「口座管理 → セキュリティ設定 → パスキー設定」
◎ 「パスキーでのみログイン」 ID・パスワードでのログインを全チャネルで止める(2026/7/25から) 「口座管理 → セキュリティ設定 → 多要素認証設定 → ログイン」。使う全端末でパスキーログインできることを先に確認。一部の資産管理アプリが使えなくなる可能性あり
◎ 出金依頼時のSMS認証・電話番号認証 出金時に取引暗証番号に加えて認証番号を求める。任意設定なので自分で有効にする 「口座管理 → セキュリティ設定 → 多要素認証設定 → 出金依頼」
○ 出金先口座の変更ロック 出金先の登録・変更を止める 顧客サポートに連絡して設定。解除は書類提出が必要。ロック状況はサイト上で確認できない
○ 口座・取引の利用制限(依頼制) ログインを含む全停止、取引のみ停止、出金のみ制限から選べる。売却のみ・買付のみの制限や、商品を指定した制限も可能 顧客サポート(0120-953-006、平日8:30〜17:00)に電話。設定も解除も電話のみで、サイト上では操作できない
自動 ログイン通知メール 必須で、オフにできない 通知先アドレスは変更可

三菱UFJ eスマート証券(旧auカブコム証券)

優先 設定 内容 場所・注意
◎ パスキー登録 2026/4/26導入。ログイン時の必須化は2026年10月末を目標に準備中 PC:「設定・申込 → お客様基本情報 → パスキー管理」。スマホ: 右上メニュー「設定・照会 → パスキー管理」。PCとスマホ両方に登録するならスマホが先
◎ 「ログイン・重要なお手続きでのパスワード認証」を無効 ログインだけでなく出金などの認証もパスキーのみになる パスキー管理画面
○ 認証メールアドレスの登録 ログイン通知と出金時の認証コードの受け取りに必要
○ 認証アプリ / 電話認証 パスキーを使えない場合の二要素認証。メールの認証コードは電話認証へ移行予定 電話番号は「連絡・通知先設定」で登録
○ 取引時のパスワード省略をオフにする 注文のたびにパスワードを求める状態にしておく 「設定・申込 → サイト機能設定 → カスタマイズ機能」
○ 約定・失効通知サービス 注文の約定・失効をメールで通知
自動 自動通知サービス メールアドレス・電話番号の変更、出金依頼の受付、出金先やパスワードの変更を通知 認証メールアドレス宛に届く
自動 出金時の二要素認証 出金パスワードとワンタイム認証コード

不正アクセスが疑われる場合は、サポートセンターへの申告でログイン・取引・出金を止めてもらえます(再開は本人からの電話)。

2. 銀行

三菱UFJ銀行

優先 設定 内容 場所・注意
◎ 振込限度額の引き下げ 普段は必要最小限にしておく ログイン後「ご利用限度額変更」
○ ワンタイムパスワード(アプリ) 振込や限度額変更の認証に使う 電話(自動音声)の本人確認で登録した場合、振込上限は10万円。免許証・マイナンバーカード・店頭なら1日最大1,000万円

○ Eメール通知 振込、住所変更、限度額変更、パスワード変更などの手続きがあるとメールが届く メールアドレスの登録・変更はインターネットバンキングで行う(ワンタイムパスワードが必要)
○ キャッシュカード・通帳の利用停止 紛失・盗難時にアプリから止められる アプリ「マイページ → カード・通帳・印鑑 → 紛失・盗難による通帳/カードの利用停止・再発行」

三井住友銀行(SMBC)

優先 設定 内容 場所・注意
◎ SMBCセーフティパス 登録すると、アプリでもPCでも、登録スマホの生体認証がないとログインできない 登録はスマホ1台まで。PCからは画面の二次元コードを登録スマホで読み取って承認
◎ 振込上限金額の引き下げ 普段は必要最小限にし、必要なときだけ引き上げる アプリ「振込 → 振込上限金額の変更など」。引き下げはワンタイムパスワード不要、引き上げは必要
○ Oliveフレキシブルペイの利用制限 カード全体、または支払いモードなどの項目ごとに利用を止められる 三井住友銀行アプリのフレキシブルペイ画面で、制限したい項目をONにする
○ デビットモードの利用限度額 海外ショッピング、海外ATMなどの上限を0円から設定できる アプリのデビットモード「利用制限」

みずほ銀行
